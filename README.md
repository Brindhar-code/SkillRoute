# SkillRoute — Student Opportunity Explorer 🌱

SkillRoute is a responsive, student-focused opportunity explorer designed to help learners discover internships, hackathons, projects, and courses in one place.

The project demonstrates frontend development concepts using HTML, CSS, JavaScript, and JSON.

## ✨ Features

- 🔍 **Live Search:** Search opportunities by title, company, category, skills, location, and description.
- 🗂️ **Category Filters:** Filter opportunities by internships, hackathons, projects, and courses.
- ↕️ **Sorting:** Sort listings by featured status, title, or company name.
- 📄 **Pagination:** Browse opportunities in manageable groups.
- 🔎 **Opportunity Details:** Open a popup to view descriptions, skills, locations, and durations.
- 🚫 **Empty State:** Displays a helpful message when no opportunities match the search.
- ⚠️ **Error Handling:** Displays an error message if the JSON data cannot be loaded.
- ⏱️ **Debounced Search:** Waits briefly after typing before filtering results.
- 📱 **Responsive Design:** Designed to work across desktop and mobile screens.
- 📦 **JSON Data:** Loads opportunity listings from a separate JSON file.

## 🛠️ Technologies Used
